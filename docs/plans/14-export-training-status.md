# Slice 14: export training status (US-13)

Part of [Extended user stories](extended-stories.md). It depends on [Slice 13](13-assignment-report.md).

## Story

[US-13](../user-stories.md#us-13--export-training-status): an administrator exports the assignments the current dashboard filters select as a CSV snapshot with a date.

## Change

### 1. Export rows in `assignment_reports.py`

Add these to [assignment_reports.py](../../training/assignment_reports.py):

```python
EXPORT_COLUMNS = (...)  # header labels, in order

def export_rows(filters, *, now, zone_name) -> Iterator[list[str]]:
    """Yield the header, then one row per assignment that report_assignments(filters, now=now) selects.
    Every cell is already safe to open in a spreadsheet."""
```

`export_rows` calls `report_assignments` and `report_rows`. **It doesn't filter on its own**, so the export can't disagree with the dashboard. Use `.iterator(chunk_size=500)` together with the attempts prefetch (Django 5.2 supports this), so a large export doesn't load everything at once.

The columns, in order:

| Column | Source |
|---|---|
| Generated at | `now` in `zone_name`, ISO 8601 with offset; the same on every row |
| Time zone | `zone_name`; the same on every row |
| Employee | `employee.name` |
| Employee email | `employee.email` |
| Employee activity | "Active" / "Inactive" |
| Training | `version.title` |
| Version | `version.version_number` |
| State | `ReportRow.state` |
| Due date | `assignment.due_date` (ISO date) |
| Progress | `ReportRow.progress` |
| Deadline status | `ReportRow.deadline` |
| Completed at | `completed_at` in `zone_name`, ISO 8601; blank if not completed |
| Latest score | `ReportRow.latest_score` |
| Passing score | `ReportRow.passing_score` |
| Assignment ID | `assignment.id` |

Putting the generation time and time zone on every row, instead of in a preamble line, keeps the file a plain table that any CSV reader can load. Leave out submitted answers, answer keys, `QuestionOption.is_correct`, notification content and history reasons.

### 2. Encode cells safely

Add a private `_spreadsheet_safe(value)` in the same module and apply it to every cell. If a string value starts with `=`, `+`, `-`, `@`, a tab or a carriage return, prefix it with `'`. Write the file with `csv.writer` and its default `QUOTE_MINIMAL` quoting. Quoting deals with commas, quotes and newlines. Then add a UTF-8 BOM so Excel detects the encoding.

Score values such as `-` or `85.0%` and ISO dates are generated by the system, but run them through the same function anyway. A rule with no exceptions is easier to check.

### 3. View and URL

- Add `export_assignments` to [assignment_admin_views.py](../../training/assignment_admin_views.py), decorated with `@require_GET` and `@demo_admin_required`. Employees get the same response the decorator gives the dashboard today.
- Route it as `path("assignments/export.csv", ..., name="export_assignments")`.
- Parse `ReportFilters.from_params(request.GET)`. If the filters are invalid, return 400 with the filter message as plain text. Don't send an empty file.
- Return a `StreamingHttpResponse` with `Content-Type: text/csv; charset=utf-8` and `Content-Disposition: attachment; filename="training-status-<YYYYMMDD-HHMM>.csv"`, using the organization time zone. Add `Cache-Control: no-store`.
- Use `settings.ORG_TIME_ZONE` as `zone_name`.

### 4. Dashboard link

In [assignment_dashboard.html](../../templates/training/assignment_dashboard.html), add an **Export CSV** link next to the active filter summary. Its `href` is `{% url 'export_assignments' %}?{{ filter_query }}`, where the view passes `filter_query = urlencode(filters.as_params())`. The link text says what it exports, for example "Export these N assignments (CSV)". It must work without JavaScript.

## Tests

Add these to `training/test_assignment_reports.py` (domain) and `training/test_assignment_export.py` (HTTP):

- `test_export_contains_exactly_the_dashboard_rows`: for several filter combinations, the assignment IDs in the CSV match the dashboard rows in the same order. Include inactive employees, archived work and a canceled row filtered by deadline.
- `test_export_records_generation_time_and_time_zone`, using an injected `now`.
- `test_export_neutralises_formula_prefixes`: employee names `=HYPERLINK(...)`, `+1`, `-2`, `@x`, and one starting with a tab.
- `test_export_omits_answers_and_answer_keys`: the attempt's option text and correct option text don't appear anywhere in the body.
- `test_export_shows_completion_time_and_scores_for_completed_work`.
- `test_employees_cannot_export`: the demo employee actor gets the same status as on the dashboard.
- `test_invalid_filters_return_400_not_a_file`.
